## Verification levels

- **Source reviewed:** the paths above and private review inventory. Existing unfinished/source-only code has not been certified as functioning production behavior.
- **Locally executed:** actual Next handler composition over temporary files, full exact-target lifecycle tests, existing focused regression tests, real Node/FFmpeg generation on synthetic test patterns. See final test JSON and runtime-check.json in the handoff for counts and commands.
- **UI exercised:** same original CSS, Inter font, mark, sidebar dimensions, page typography and pipeline geometry; dark/light/mobile screenshots from synthetic original and Site fixtures, plus actual local framework browser checks. Visual equivalence does not establish data or workflow parity.
- **Hosted:** owner-private Site UI and closed authenticated command boundary only. Worker connection and all mutation capabilities remain unavailable.
- **Unrun:** live source ingestion, production ledger reads/writes, platform verification, real social post, original-service deployment and cutover. These need a supported transport and separately scoped authorization.

One original owning ledger remains authoritative. No original files/data/users/settings are migrated or removed. No independent publishing queue, credential, OAuth grant, paid service or schedule is created. Complete functional parity remains pending the gaps above.
