## Synthetic runtime evidence in this lane

`auth.test.ts` and `http.test.ts` exercise the complete native Request/Response boundary using injected synthetic authentication and services. All 64 cases pass. The focused strict TypeScript check passes. The cases prove schema/origin/owner/scope enforcement, body-byte limits, strict UTF-8/JSON handling, callback isolation, no-store responses and conservative failure handling. They do not prove a deployed authenticated transport, actual queue mutation, media generation, worker execution, platform delivery or analytics synchronization.

## Visual parity

Appearance is a separate verification track. Reusing the original theme, typography, shell and components can establish visual parity only when compared in the same viewport and host appearance mode. It cannot establish end-to-end functional equivalence. An owner-private hosted Site has a different runtime from the original Node application; native filesystem access, FFmpeg work, large uploads and scheduled execution remain in the original worker unless explicitly integrated and verified.
