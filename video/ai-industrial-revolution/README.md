# AI: The Industrial Revolution of Modern Times

Remotion vertical short (1080×1920 @ 30fps, 25s) — a hook/intro segment
making the claim that AI is the industrial revolution of our time, and that
step 1 is choosing the right model.

## Scenes

| Scene        | Duration | Beat                                             |
| ------------ | -------- | ------------------------------------------------ |
| ColdOpenHook | 3s       | "AI is the new industrial revolution"            |
| ThenVsNow    | 6s       | 1800s steam vs today's AI — same shift           |
| StepOne      | 5s       | STEP 1 → choose the right model                  |
| ModelPicker  | 7s       | Match the model to the job (fast / balanced / big brain) |
| EndCard      | 4s       | Step 1 of the series → next: put it to work      |

## Commands

```sh
npm install
npm run preview   # Remotion Studio
npm run render    # out/ai-industrial-revolution.mp4
npm run still     # out/poster.png
```

These scenes are also wired into the app's Segment Deck at `/presentation`
(see `src/app/presentation/deck.tsx`).
